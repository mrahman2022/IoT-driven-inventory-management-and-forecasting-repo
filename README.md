# IoT-Driven Inventory Management and Demand Forecasting Optimization Using Machine Learning

## Project Overview
This project explores an IoT-based inventory monitoring system integrated with machine learning for demand forecasting and inventory optimization.

## Technologies
- ESP32-S3 microcontroller
- Raspberry Pi 5
- Environmental, distance, weight and RFID sensors
- MQTT communication
- Python and machine learning

## Repository Structure
- `Documentation/` – Technical documentation
- `Firmware/` – Microcontroller firmware
- `Hardware/` – Hardware design
- `MachineLearning/` – Forecasting scripts
- `Dataset/` – Dataset and visualizations
- `Software/` – Application software
- `Literature/` – Research references
- `Images/` – Supporting figures
